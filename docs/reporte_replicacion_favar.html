Objetivo de la Replicación

El principal objetivo de este ejercicio es implementar y evaluar la validez empírica del modelo Factor-Augmented Vector Autoregressive (FAVAR) propuesto por Bernanke, Boivin y Eliasz (BBE). Específicamente se busca:

  • Resolver el sesgo de información (Price Puzzle): Evitar el comportamiento contraintuitivo de los modelos VAR de pequeña escala, en los cuales una política monetaria restrictiva parece incrementar los niveles de precios de forma transitoria debido a la omisión de variables relevantes.
  • Evaluar la transmisión macroeconómica: Estudiar cómo un choque en las tasas de interés se transmite de manera consistente a múltiples sectores de la economía estadounidense (empleo, producción, vivienda y tasas de interés de mercado).

El Proceso de Estimación

Para estimar de manera robusta el modelo FAVAR, se desarrolló un pipeline analítico en Python estructurado en tres pasos clave:

1. Procesamiento del Panel (X): Se descargó el vintage mensual FRED-MD y se aplicaron transformaciones matemáticas específicas para inducir estacionariedad en cada variable según su naturaleza:

Transformaciones: Diferencias simples (Δx_t), Logaritmos (ln x_t) y Diferencias de Logaritmos (Δ ln x_t).

2. Extracción de Factores: Se estimaron factores comunes usando Análisis de Componentes Principales (PCA). Para separar la contribución del instrumento de tasas de interés (FEDFUNDS) del espacio lento de la economía, se realizó una regresión lineal de los componentes y se extrajo el componente puro correspondiente al factor latente macroeconómico ($F_t$).

3. Estimación del VAR Dinámico: Se ajustó un modelo VAR estructural de 13 rezagos y se estimaron las funciones de impulso-respuesta ortogonalizadas a través de una descomposición recursiva de Cholesky:

Z_t = [F_t, FEDFUNDS_t]^T \quad \rightarrow \quad Z_t = \Phi(L) Z_{t-1} + v_t
